**Tipo de proyecto**
Software como servicio para la gestión y visualización de datos de inundaciones en tiempo real.

**Modalidad de implementacion**
Proyecto con IA / Ingenieria de IA / VibeCoding

**Problema Inicial**
La gestión y visualización de datos de inundaciones en tiempo real es un desafío para las autoridades y los ciudadanos.

**Usuario Identificados**

*Ciudadano*: Reporta inundaciones y visualiza zonas afectadas en tiempo real.

*Operador*: Gestiona los reportes de inundaciones y visualiza el estado de las zonas afectadas.
